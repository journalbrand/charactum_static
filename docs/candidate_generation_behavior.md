# Candidate Generation Behavior

When new nodes are generated by the LLM the application automatically shows the footer pane so the analysis is immediately visible.  The candidate analysis panel replaces the regular graph statistics while it is active.

Users no longer need to manually expand the panel after generating candidates.  Dismissing or approving the candidates leaves the panel state unchanged.
The **Generate Candidates** button remains disabled and appears faded until a relationship type is selected.
